## Parser implementation notes

- `TypeExpr` now preserves named types, n-ary unions/intersections, and explicit groups recursively. `TypeRef` retains its old fields as a compatibility projection while semantic and IR consumers migrate. Generic type arguments parse full type expressions.
- Intersection binds more tightly than union. Grouping is represented explicitly, including a grouped union inside an intersection followed by another outer union; a parser test checks that no alternative is overwritten.
- Intersections and nested algebraic forms are rejected by semantic analysis with `NOT_LOWERED` until their type relations and runtime/lowering behavior exist. Simple ungrouped unions continue through the existing semantic path.
- The parser nesting guard is 48 because the expanded reference/AST representation caused the 96-level regression fixture to overflow the standard 2 MB test thread before it could emit its diagnostic. The focused boundary fixture and the complete parser crate suite now pass at the standard stack size.
- Type-position values for Boolean, integer, Float/Decimal syntax, Duration, String, Char, and Null preserve typed payloads and token spans. `const(...)` retains the exact inner source slice, parsed expression tree, and type-atom span.
- Constant-type syntax parses its inner expression with ordinary expression grammar and recovers at the next declaration after malformed or incomplete input. The bounded evaluator now handles scalar values, pure arithmetic, temporal constructors, interpolation, typed const functions, effect rejection, and fuel/depth/output limits. The bounded evaluator supports immutable object-literal aggregates with recursively evaluated fields, deterministic structural type identity, sorted canonical keys, and explicit rejection of spreads, computed keys, and duplicate fields. User-defined immutable class aggregate construction and semantic singleton runtime lowering remain unimplemented.
- Anonymous object type syntax records optionality and `inmut` read-only properties; duplicate keys receive a parser diagnostic. Shape assignability and contextual object selection remain unimplemented.

| `IntersectionType` | `PostfixType (& PostfixType)*` | Every operand remains an independent recursive child; no flat-list overwrite is allowed. | Implemented and covered. |

| Mapped shape | `{ [K in keyof T] [as KeyExpr] [Modifier] [?] : TypeExpr }` | The `in` token inside the bracketed key clause distinguishes a mapped member from an ordinary computed property. | Pending. |
| Template singleton | Backtick-delimited text with `${TypeExpr}` substitutions | This is a type-only token form, separate from runtime String interpolation; finite products are bounded by the template budget. | Pending. |

## Public grammar and ambiguity resolutions (tasks 1.3 and 1.5)

The public grammar is defined in `design.md` and the delta specifications. This table fixes the boundaries that are easy to misparse and is the parser conformance checklist:

| Form | Grammar rule | Ambiguity resolution |
| --- | --- | --- |
| Union/intersection | `Union := Intersection ("|" Intersection)*`; `Intersection := Postfix ("&" Postfix)*` | `&` binds tighter than `|`; both operators are n-ary. Parentheses preserve source grouping in the AST; semantic canonicalization may remove redundant groups. |
| Nullable/array | `Postfix := Atom ("?" | "[]")*` | `T?` is exactly `T | Null`; suffixes bind before union/intersection. Fixed-array length and future indexed access are distinct productions. |
| Generic reference | `Name "<" Type ("," Type)* ">"` | Each argument accepts a full union expression; commas and `>` close the argument list. Nested `>>` closes nested generic lists without whitespace. |
| Literal singleton | A literal token in type position, or `const("(" ConstExpr ")")` | Literal tokens are singleton types only in type position. `const` introduces an evaluated value type there; normal expression calls retain expression grammar. |
| Structural shape | `"{" Property (";" | ",")* "}"`; `Property := [inmut|mut] Identifier [?] ":" Type` | `inmut` is read-only, `mut` writable, omitted modifier uses the language default. Optionality controls presence separately. Duplicate names are diagnosed before resolution. |
| Generic alias | `type Name "<" TypeParam ("," TypeParam)* ">" "=" Type`; each parameter may have `from Constraint` and `= Default` | Parameters scope only over the alias body; defaults follow constraints. Arity/constraint errors are semantic, not parser recovery. |
| Conditional | `CheckType extends ConstraintType ? TrueType : FalseType` | `extends` starts the conditional layer after the check type; the first unmatched `?` pairs with its `:`. Parentheses disambiguate nested conditionals. `infer` bindings exist only in the true branch. |
| Mapped shape | `{ [K in keyof T] [as RemappedKey] [readonly|inmut|mut] [?] : ValueType }` | `[K in ...]` selects mapped-member grammar only inside a type shape. Modifiers apply to output fields. Ordinary runtime computed properties are not type-level mapped members. |
| Template type | Backtick-delimited type text with `${Type}` holes | Recognized only in type position, distinct from runtime interpolation. Text is exact UTF-8; holes accept a type expression and expansion is deferred to bounded semantic evaluation. |

Recovery stops at the nearest enclosing type delimiter (`)`, `>`, `,`, `;`, `}`, or declaration boundary), preserving the following declaration. Incomplete const, generic, conditional, mapped, and template forms require focused recovery tests. The parser currently implements recursive union/intersection, scalar literals, `const(...)` shells, and ordinary object shapes; conditional, mapped, and template productions remain unavailable and must not be presented as implemented.

Compile-time resource limits are deterministic: constant evaluation uses 100,000 fuel steps, 32 call frames, aggregate nesting 64, and a 1 MiB canonical-value limit; relation solving uses 100,000 memoized pair visits per analysis snapshot and recursion depth 256; template expansion uses at most 10,000 generated union members and 1 MiB of generated type-source bytes. Exhaustion reports `E0482` at the triggering source span with the operation category and configured bound. No evaluator, relation solver, or template expander may truncate, return a partial type, silently widen, or panic on exhaustion. Changing a budget requires stress evidence and a deliberate spec update. The constant-call limit was reduced from 128 after reproducing stack overflow at the old bound on Rust's default test-thread stack; the recursive-call exhaustion test now passes at 32 without increasing the test stack.

`crates/zirk-sema/src/constant_value.rs` defines a versioned, deterministic typed-value encoding with type identity, exact-width integer identity and full `UInt128` representation, exact Decimal normalization, Float width validation/NaN rejection/signed-zero canonicalization, and recursively typed enum, tuple, and aggregate payloads. The compact signed payload handles values through `i128::MAX`; `BigUnsigned` preserves the upper UInt128 range under the same canonical integer tag and 16-byte representation.
