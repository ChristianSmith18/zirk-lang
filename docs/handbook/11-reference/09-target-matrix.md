# Target Matrix

Initial families cover supported combinations of Windows, Linux, and macOS; `x86`, `x86_64`, `armv7`, and `aarch64`; and PE, ELF, and Mach-O. Suggested names include `x86_64-linux`, `aarch64-linux`, `x86_64-windows`, `aarch64-macos`, and `x86_64-macos`.

Actual availability depends on LLVM, linker, SDK, runtime, stdlib, and native dependencies. Modern 32-bit macOS, WebAssembly, and browser targets are not promised in Zirk 1.x.
