# Built-in Types

- Signed: `Int8`, `Int16`, `Int32`, `Int64`, `Int128`, aliases `Int` and `Integer`.
- Unsigned: `UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`.
- Decimal: `Decimal16`, `Decimal32`, `Decimal64`, `Decimal128`, aliases `Dec` and `Decimal`.
- Fundamental: `Boolean`, `Char`, `String`, `Void`, `Never`, `Null`, `Object`.
- Core generic families: nullable `T?`, `Result<T,E>`, arrays, `List<T>`, `Map<K,V>`, `Set<T>`, `Range<T>`, `Task<T>`, `Thread<T>`, `Channel<T>`, `Atomic<T>`, and `Resource<E>` implementers.
