# Learning Paths

The handbook is comprehensive, but not every reader needs the same introduction. These paths connect existing experience to Zirk's actual semantics and then return you to the full language chapters.

- [New programmers](./01-zirk-for-new-programmers.md) learn concepts and syntax together.
- [TypeScript programmers](./02-zirk-for-typescript-programmers.md) focus on native compilation, nominal contracts, resources, and explicit concurrency.
- [Python programmers](./03-zirk-for-python-programmers.md) focus on static types, declarations, nullability, and build-time guarantees.
- [Rust, C, and C++ programmers](./04-zirk-for-rust-c-cpp-programmers.md) focus on automatic memory, safe defaults, explicit unsafe code, and the runtime model.
- [Java and C# programmers](./05-zirk-for-java-csharp-programmers.md) focus on inference, algebraic data, structured concurrency, and project capabilities.
- [Tooling in Five Minutes](./06-tooling-in-five-minutes.md) tours the development loop.

Each path is a map, not a substitute for feature documentation. When familiar syntax hides a semantic difference, follow the linked handbook chapter rather than relying on analogy.
