# `std.reflect`

Basic type identity is always available; structural metadata exists only when retention was requested. Missing metadata produces an explicit result or diagnostic.

Reflection cannot violate visibility or mutability. The compiler's immutable Syntax API is a separate tooling API, not part of `std.reflect`.
