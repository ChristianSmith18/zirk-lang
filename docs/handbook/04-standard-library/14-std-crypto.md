# `std.crypto`

The module exposes modern audited algorithms, system CSPRNG, safe defaults, constant-time comparison where needed, and distinct types for keys, nonces, and hashes.

Obsolete algorithms are not enabled for convenience. Native-backed implementations must be verified and preserve target, packaging, and permission contracts. Secrets must not appear in diagnostics.
