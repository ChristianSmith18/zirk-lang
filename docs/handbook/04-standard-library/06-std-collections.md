# `std.collections`

The module provides dynamic and fixed arrays, `List<T>`, `Map<K,V>`, `Set<T>`, `Range<T>`, iterators, and safe views. Index access is checked; optional access represents absence.

`map`, `filter`, and `reduce` do not mutate the source. Search, sorting, conversion, ordering, allocation, and iterator invalidation are documented per operation.
