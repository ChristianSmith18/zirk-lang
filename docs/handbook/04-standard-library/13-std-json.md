# `std.json`

`std.json` offers a typed JSON tree and generic encode/decode. Derived serializers may use decorators or explicitly retained reflection metadata.

Parse errors include source location, JSON path, and expected type. Depth and size limits defend against hostile inputs. Decoding never bypasses constructors or type invariants silently.
