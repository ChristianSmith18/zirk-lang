# Standard Library

Zirk's initial standard library is deliberately small, typed, cross-platform, and explicit about I/O, permissions, failure, blocking, and cancellation. Standard modules use unquoted imports; specialized frameworks remain packages.

Use the [Standard Library Indexes](19-standard-library-indexes.md) to find an API
by task, module, type, error family, permission, waiting/cancellation behavior,
or complexity. The index links back to the owning module rather than duplicating
its complete contract.
