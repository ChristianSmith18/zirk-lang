# Data Types

Zirk offers several ways to model domain data. Records emphasize named structure, value classes create a distinct value abstraction, enums define closed alternatives, aliases name an existing type, and unions admit explicitly listed types.

Choosing among them determines construction, equality, identity, exhaustiveness, and API compatibility—not merely spelling.
