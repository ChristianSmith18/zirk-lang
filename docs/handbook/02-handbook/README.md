# The Zirk Language Handbook

This is the progressive guide to Zirk source code. It begins with files and bindings, develops the type and object models, and then moves through errors, resources, safety, concurrency, and modules.

The chapters teach the normative Zirk 1.x design. A construct may still be missing from the current compiler; status notes distinguish that implementation gap from the language contract.

## Reading strategy

Read in order when learning Zirk. Each unit assumes vocabulary introduced earlier. Experienced readers may enter through a section overview, but should follow links when Zirk gives a familiar-looking construct different semantics.

Every leaf chapter answers one focused question. Section overviews connect those answers and show the larger mental model.
