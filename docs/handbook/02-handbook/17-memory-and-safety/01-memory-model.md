# Memory Model

The public model defines values, identity, references, mutation, concurrency safety, and observable lifetime. Stack, heap, regions, moves, reference counting, and garbage collection are internal strategies that may be combined.

Representation cannot change equality, identity, or observable lifetime. Objects retain identity even if the runtime moves their storage.
