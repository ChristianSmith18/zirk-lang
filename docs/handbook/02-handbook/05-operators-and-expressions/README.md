# Operators and Expressions

Operators are compact syntax for type-defined behavior. Zirk fixes their arity and precedence; overloadable operators must follow language contracts and cannot invent a new parse.

This unit covers arithmetic, comparison, structural equality, identity, logic, conditional selection, updates, pipelines, ranges, and overloading.
