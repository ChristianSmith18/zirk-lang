# Program Structure

Before values have types or functions perform work, Zirk needs an unambiguous source structure. This unit explains `.zrk` files, tokens, comments, statement boundaries, blocks, scopes, and naming conventions.

Zirk is case-sensitive, uses braces for blocks, and supports optional parser semicolons when no ambiguity exists. The official formatter writes semicolons, making the repository representation deterministic.
