# Concurrency and Parallelism

Concurrency structures overlapping work; parallelism requests simultaneous CPU execution. A concurrent operation waiting for I/O does not consume a thread, while `parallel` divides CPU work across the runtime pool. Choose by intent, not performance folklore.
