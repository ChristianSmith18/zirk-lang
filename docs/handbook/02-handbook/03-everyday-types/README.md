# Everyday Types

Zirk's fundamental types cover numbers, truth values, Unicode text, control-flow results, and durations. They are statically checked and participate in the common object model, though their runtime representation may be inline.

This unit explains the hierarchy and the conversions or safety rules that prevent familiar numeric and text bugs.
