# Project Layout

```text
my_app/
├── init.zrk
├── zirk.lock
├── src/main.zrk
└── test/
```

The manifest and lockfile sit at the root. Source and tests remain distinct; generated artifacts belong to tool-managed output locations rather than the source tree.
