# Entry Point

The `project.entry` file contains the sole executable `main` symbol.

```zirk
fn main(): Void { /* ... */ }
```

`main(): Void` exits successfully. Other code/result forms follow the entry-point contract. Process arguments come from `std.process`, not a mandatory parameter.
