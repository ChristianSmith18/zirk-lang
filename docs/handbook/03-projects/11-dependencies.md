# Dependencies

Manifest dependencies name packages and resolution constraints. `zirk add`, `remove`, and `install` maintain them; native dependencies additionally constrain targets and ABI.

Resolution must be deterministic and auditable. A package's typed API, permissions, license, and target compatibility matter as much as its version.
