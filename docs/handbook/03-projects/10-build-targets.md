# Build Targets

`build_targets` can request several native targets. `zirk build --target <target>` overrides them for one invocation; otherwise the host is detected.

Support depends on LLVM, linker, SDK, and native dependencies. Zirk 1.x targets supported Windows, Linux, and macOS combinations—not WebAssembly/browser.
