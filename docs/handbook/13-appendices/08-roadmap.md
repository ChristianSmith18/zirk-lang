# Roadmap

The handbook targets normative Zirk 1.x, not an invented implementation schedule. Progress should move from frontend and diagnostics through types/flow, IR/backend, runtime, stdlib, packages, and integrated tooling, with conformance tests for every feature.

Future features require an explicit specification change, compatibility analysis, implementation milestone, tests, and documentation update. Excluded 1.x ideas are not automatically roadmap commitments.
