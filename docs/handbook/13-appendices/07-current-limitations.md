# Current Limitations

The language is under implementation. The normative documents still lack a complete machine grammar, precedence table, stable diagnostic-code registry, and final detail for ranges, slicing, traditional `for`, alternative patterns, value-class syntax, and generators.

Zirk 1.x explicitly excludes browser/WebAssembly, public runtime directives/event loop, standalone `worker`, `async fn`, inline assembly, general `comptime`/`defer`, multiple class inheritance, traditional overloads, `Result ?`, and public ownership/RC.
