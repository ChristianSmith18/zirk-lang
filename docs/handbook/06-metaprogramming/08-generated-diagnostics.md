# Generated Diagnostics

Diagnostics from generated code show the original source span and the relevant expansion. A decorator can emit typed diagnostics through the Syntax API, but should identify the user's actionable input rather than only its generated node.

Stable compiler diagnostic structure still requires severity, code, location, cause, and repair guidance when available.
