# Tutorials

These tutorials assemble language features into complete projects. Each begins with a manifest and contract, implements one vertical slice, handles failure and permissions, adds tests, and ends with check, format, lint, test, and build commands.

> **Implementation status:** Examples follow the normative Zirk 1.x design. Confirm feature support in your compiler revision before expecting every command to execute.
