# Class, Record, or Value Class?

Use a class for identity and lifecycle, a record for structural named data, and a value class for a distinct compact domain value. This choice determines equality, identity, mutation, construction, and compatibility—not guaranteed allocation.

Choose from domain semantics first; allow the compiler to optimize representation second.
