Small, typed, portable

Standard library

The initial library covers native application essentials. APIs prefer enums to magic strings, Result to hidden failure, typed Path values and cancelable waiting.

I/O, files and system

ModulePrincipal API and behaviorFailure / capability
std.iostdin, stdout, stderr; text, char and byte I/O; async variantsReadResult distinguishes data, EOF and error
std.fsFile, typed open modes, read/write/metadata, idempotent closeFileError; scoped read/write permission
std.pathPath, join, components, normalization, canonicalizationCanonicalization accesses filesystem and needs permission
std.processrun, spawn, typed stdio, timeout, child resourceProcess/environment permission; shell is separate and dangerous
std.systemPortable process, target, environment and signal informationSensitive environment/signal access is capability-gated

Collections, data and time

ModuleContract
std.collectionsArray, fixed arrays, List, Map, Set, Range, iterators and non-mutating functional operations. Indexing is checked.
std.timeDuration, monotonic instants, civil time, versioned zones, cancelable timers. Duration and civil time never mix implicitly.
std.jsonTyped JSON tree and generic encode/decode. Errors carry location, path and expected type; depth/size limits defend hostile input.
std.reflectBasic type identity and explicitly retained structural metadata. It cannot bypass visibility or mutability.

Networking and cryptography

ModuleContractOperational notes
std.netAddresses, DNS, TCP and UDPCancelable reactor I/O; network permission
std.httpTyped client/server, headers, streaming, TLS, timeoutsBackpressure and disconnect cancellation; no thread per request
std.cryptoAudited modern algorithms, CSPRNG and strong key/nonce/hash typesSafe defaults, constant-time comparison where required; obsolete algorithms excluded

Testing and benchmarks

std.testing supplies assertions for equality, identity, truth, nullability, results, exceptions, collections and decimal approximation. @test is valid only in .spec.zrk; @e2e lives in test/*.e2e.zrk; @bench adds warmup, repeated samples and machine-readable statistics.

user_service.spec.zrk
@test
fn creates_user(): Void {
    assert.equal(actual, expected);
}
Common contract. Public APIs document allocation, blocking, cancellation, thread safety and required permissions. Expected operational failure uses a typed result.
