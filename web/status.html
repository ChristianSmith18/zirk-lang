Phase 0 · foundations

What works today

Zirk's documentation describes the intended mature language. The implementation is deliberately building the riskiest native backend foundations before the frontend syntax.

Zirk does not compile Zirk source yet. Examples throughout this website are normative targets, not claims of current executable support.

Roadmap shape

  1. Phase 1: minimum end-to-end language pipeline and first native program.
  2. Phases 2–4: core surface, objects/types, errors, memory and safe low level.
  3. Phase 5: tasks, channels, OS threads, parallelism and race analysis.
  4. Phases 6–8: project system, stdlib, packages and distribution.
  5. Phases 9–11: developer experience, metaprogramming and production hardening.
  6. Phase 12: eventual self-hosting after the language is mature.

Each phase ends only when its stated output runs with tests. Future features remain documented so architecture can converge on a coherent language, but implementation does not jump ahead of phase dependencies.

How to read these docs

Treat language, runtime, compiler and stdlib pages as the public design contract. Treat this page, the repository README and roadmap as the source for current availability. Normative source documents remain authoritative when explanatory prose is abbreviated.
