Get started with Zirk

Install the native toolchain, create a project and understand the small program that becomes your first standalone binary.

Prerequisites

The compiler is built with Rust and LLVM 20.1. During Phase 0, contributors use the repository toolchain documented in TOOLCHAIN.md. A future distribution exposes the same workflow through the zirk executable.

Current availability. Zirk does not compile .zrk source yet. Examples below are the normative Phase 1 interface and are intentionally marked as specification material.

1. Create a project

Terminal
zirk new hello-zirk
cd hello-zirk

A project has an init.zrk manifest and source directory. The manifest is declarative; it is not executable Zirk code.

init.zrk
project {
    name: "hello-zirk";
    type: application;
    version: "0.1.0";
}

build_targets { x86_64-linux; aarch64-macos; }

2. Write the first program

src/main.zrk · Zirk
import { stdout } from std.io;

fn main(): Void {
    inmut name: String = "Zirk";
    stdout.println("Hello, {name}!");
}

import makes the typed stdout stream available. fn main(): Void is the program entry point. inmut makes the binding non-reassignable, and interpolation inserts the string value.

3. Check, run and build

Terminal
zirk check
zirk run
zirk build --target aarch64-macos

check runs the incremental frontend without LLVM. run builds and executes. build emits a native artifact for the selected target. Produced application binaries are standalone: users do not install Zirk, Rust, Python, Node.js or a VM.
