Language reference

Language fundamentals

Zirk is case-sensitive, statically typed and expression-friendly. Braces define blocks; the formatter writes semicolons even where parsing is unambiguous.

Lexical structure

Names follow snake_case for values and functions, UpperCamelCase for types, and UPPER_SNAKE_CASE for constants. Both // and /* … */ comments are accepted. Source files use .zrk.

bindings.zrk
mut count: Int32 = 0;
inmut NAME: String = "Zirk";
inmut::strict config: Config = Config();

mut permits reassignment. inmut fixes the reference while respecting the referenced type's mutability. inmut::strict prevents transitive modification.

Values and operators

There is no numeric truthiness and no undefined. Logical operators accept Boolean. == is structural equality; is tests observable identity. Numeric overflow is controlled, and lossy conversion is explicit.

Control flow

if, for, for … in, while, loop, break and continue are built in. if and exhaustive match can produce values.

match.zrk
inmut message = match result {
    Ok(value) { "Value: {value}" }
    Error(error) { "Error: {error}" }
};

Expression matching must be exhaustive. Patterns cover values, types, algebraic enums, unions and destructuring. Resource-aware match with is documented in Errors and safety.

Functions and closures

functions.zrk
fn greet(name: String = "world"): String {
    return "Hello, {name}";
}
inmut double = (value: Int32): Int32 => value * 2;

Functions support optional, named, default and variadic parameters. Zirk avoids traditional overload sets; use unions, generics or distinct names. Closures safely capture immutable values; shared mutable capture requires proven safety or synchronization.

Modules and conversion

modules.zrk
share class User {}
import { User, Role -> DomainRole } from "./domain/user";
import { stdout } from std.io;

mut text = source as String;
mut node = <Node>source;

share publishes a declaration. Local import paths are quoted and omit .zrk; standard modules are unquoted. Checked conversions use constructors or typed methods, while explicit casts use postfix as or prefix <T>.
