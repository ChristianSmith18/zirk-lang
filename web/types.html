Static + inferred

Types and objects

Every value has a semantic type. Local inference removes noise, while explicit boundaries keep APIs, conversions and concurrency understandable.

Built-in families

Signed and unsigned integers span 8–128 bits. Decimal types span 16–128 bits. Int/Integer and Dec/Decimal name defaults. Core values include Boolean, Unicode Char, grapheme-aware String, Void, Never, Null and Object.

Collections include dynamic and fixed arrays, List<T>, Map<K,V>, Set<T> and Range<T>. Functional operations do not mutate their source.

Classes and contracts

user.zrk
class User implements Serializable {
    public inmut id: UInt64;
    public mut name: String;
    construct(id: UInt64, name: String) {
        this.id = id; this.name = name;
    }
}
mut user = User(1, "Ada");

Construction uses construct, never new. Classes can extend one class and combine interfaces and traits. Visibility is public by default; private and protected narrow it. Traits may carry reusable implementation.

type creates aliases. Algebraic enums and unions compose with exhaustive matching. clone() exists only through an explicit trait.

Generics

generic constraint
fn serialize<T from Serializable>(value: T): String {
    return value.to_json();
}

from constrains a parameter. Concrete instantiations may be specialized. Zirk uses generics, unions and descriptive function names instead of ambiguous overload sets.

Decorators and reflection

Native decorators are compile-time functions declared with fn dec. Typed target blocks such as class(target) and method(target) operate through a versioned Syntax API. They cannot mutate private AST internals or access files, processes or the network without compile_permissions.

Basic type identity is always present; structural runtime metadata is retained only when requested. There is no general comptime {} in Zirk 1.x.

Pointers and unsafe boundaries

explicit low level
unsafe {
    mut pointer: Pointer<Int32> = &value;
    *pointer = 20;
}

unsafe enables specific operations; it does not disable type checking, scopes, mutability or permissions. Safe references are non-null and lifetime-checked. Native interoperability crosses a stable C ABI.
